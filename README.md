# InsightIQ

An AI-powered business intelligence and research copilot combining LLMs, retrieval-augmented generation (RAG), and business analytics.

## Current Features

- Gemini LLM integration
- Gemini embeddings
- ChromaDB vector storage
- Document retrieval and grounded question answering
- Streamlit interface

## Planned Features

- PDF document ingestion
- CSV and Excel analytics
- LangGraph agent workflows
- n8n workflow automation
- RAG evaluation and observability

## Tech Stack

Python, Streamlit, Google Gemini API, ChromaDB, pandas, Plotly.

## Setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies from `requirements.txt`.
4. Create a `.env` file containing your `GEMINI_API_KEY`.
5. Run `streamlit run app.py`.
